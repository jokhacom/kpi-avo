# Надстройка Unoom KPI для Excel

Панель Unoom справа в Excel: открываете свой файл с данными, нажимаете **«Рассчитать»**, и надстройка сама читает лист, считает KPI и премии по правилам сайта и создаёт лист **«Сумма KPI»**.

Формула та же, что на сайте: обе части подключают один файл `kpi-core.js`. Настройки KPI (показатели, веса, база премии, норма часов, налог) берутся с сайта после входа под тем же логином.

## Какой нужен файл

- В столбце **A** указаны имена сотрудников.
- В **первой строке** указаны названия показателей, как в «Настройках KPI» на сайте.
- Столбец **«Часы»** можно не добавлять. Без него берётся норма часов из настроек.
- Это тот же формат, что принимает импорт на сайте. Пример лежит в `excel/primer-kpi.xlsx`.

## Установка (без администратора)

Файл надстройки называется `excel/manifest.xml`. Перед установкой проверьте, что адрес сайта в нём правильный (`https://kpi-avo.vercel.app`).

- **Excel в браузере:** Вставка → Надстройки → «Мои надстройки» → «Загрузить мою надстройку» → выбрать `manifest.xml`.
- **Excel на Windows:** положить `manifest.xml` в общую папку. В Excel откройте Файл → Параметры → Центр управления безопасностью → Параметры → «Доверенные каталоги надстроек», добавьте эту папку и отметьте «Показывать в меню». Перезапустите Excel, затем Вставка → Мои надстройки → «Общая папка».
- **Excel на Mac:** скопировать `manifest.xml` в `~/Library/Containers/com.microsoft.Excel/Data/Documents/wef` (папку `wef` создать, если её нет) и перезапустить Excel.

После установки на вкладке «Главная» появится кнопка **Unoom KPI**.

Нужен Excel из Microsoft 365 (Windows, Mac или Excel в браузере). Excel 2013 и 2016 «коробочные» не подходят.

## Если поменяется адрес сайта

Замените `kpi-avo.vercel.app` в `manifest.xml` на новый адрес и установите надстройку заново.
